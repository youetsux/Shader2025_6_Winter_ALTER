# GitHub Copilot用マスタープロンプト

## 使い方

各章を実装するとき、最初にこのマスタープロンプトを貼り、その後に各章の「Copilotへの指示」を貼る。

---

## マスタープロンプト

```text
このプロジェクトは DirectX 11 / C++ / HLSL の教材用プロジェクトです。

目的は、Before版のプロジェクトにシャドウマップを段階的に追加することです。

重要な条件：
- ステンシルは使わない。
- シャドウマップを作成し、Simple3D.hlsl のピクセルシェーダーで深度比較して影を出す。
- 比較には SamplerComparisonState と SampleCmpLevelZero を使う。
- 既存のファイル構成、関数名、型名、描画の流れをできるだけ保つ。
- 存在しない補助クラス、便利関数、ダミー関数を勝手に作らない。
- 1章ごとのコミット単位で、不要な先回り実装をしない。
- 画面が変わらない章では、ビルドが通ることを成功条件にする。

最終的な描画の考え方：
1. ライト視点のビュー行列・射影行列を作る。
2. パス1で、ライト視点から影を落とすモデルを描き、Z値だけをシャドウマップに保存する。
3. パス2で、通常カメラから描画する。
4. Simple3D.hlsl のPSで、今のピクセルをライト視点に変換する。
5. シャドウマップのZ値と現在ピクセルのZ値を比較する。
6. 奥にあれば影として暗くする。
```
