# 変更ログ：bias 値の調整履歴

## 目的
セルフシャドウアクネ（ドーナツ表面のザラザラノイズ）を抑えるため、bias 値を段階的に調整した。

---

## 変更ファイル

### Simple3D.hlsl（PS() 内）

#### 第7章時点（初期値）
```hlsl
float bias = 0.005;
```
→ ジャギーバージョンの確認用。通常サンプラー版の初期値。

#### 第8章後（比較サンプラー導入後に調整）
```hlsl
float bias = 0.01;
```
→ 比較サンプラー導入後にセルフシャドウが目立ったため 0.005 → 0.01 に変更。

#### 現在の値
```hlsl
float bias = 0.015;
```
→ さらにセルフシャドウが残ったため 0.01 → 0.015 に変更。現在の実装値。

---

## bias 値の目安

| 値 | 状態 |
|---|---|
| 小さすぎる（0.005未満） | セルフシャドウアクネが出やすい |
| 0.015 | 現在の設定。アクネを抑えつつ影の位置も概ね正常 |
| 大きすぎる（0.03以上） | 影が浮いたり、本来影になるべき場所が明るくなる |
