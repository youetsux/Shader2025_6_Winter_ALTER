# シャドウマップ授業用資料 README

## 目的

この資料は、`Shader2025_6_Winter_ALTER_Befor` を出発点にして、ステンシルを使わず、シェーダー側の深度比較でシャドウマップを完成させるための授業用手順です。

完成形は `Shader2025_6_Winter_ALTER_NOW` の内容を基準にしています。

## 方針

- ステンシル比較は扱わない。
- 影判定は `Simple3D.hlsl` のピクセルシェーダー内で行う。
- 1章ごとに1コミットできる単位に分ける。
- 各章は GitHub Copilot に貼りやすいように、目的・変更ファイル・実装指示・確認ポイントを分けて書く。
- 学生には「今やっている変更で画面が変わるか／変わらないか」を毎回明示する。

## 推奨ブランチ名

```bash
git checkout -b lesson/shadowmap-no-stencil
```

## 授業で最初に伝える要点

```text
シャドウマップは、ライトから見たZ値メモ。

1回目の描画で、ライトから見た「一番手前のZ値」を保存する。
2回目の描画で、今描いているピクセルをライト視点に変換する。
同じ場所のZ値を比べる。
今描いているピクセルの方が奥なら、手前に別の物があるので影。
```

## Copilotに作業させるときの基本文

各章の「Copilotへの指示」をそのまま貼る。  
ただし、Copilotが勝手に別方式を提案した場合は、次の条件を必ず守らせる。

```text
ステンシルは使わない。
完成形は、シャドウマップを作り、Simple3D.hlsl のピクセルシェーダーで SampleCmpLevelZero によって深度比較する方式にする。
既存のファイル構成・関数名・型名に合わせる。
存在しない補助クラスやダミー関数を作らない。
```
