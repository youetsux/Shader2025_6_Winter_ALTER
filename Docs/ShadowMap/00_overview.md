# シャドウマップ実装ガイド

## 完成イメージ

ドーナツが床に影を落とす。ライト方向を WASD キーで動かすと影も動く。

---

## 進め方

必ず1Stepずつ実装してビルドする。  
画面が変わらなくてもビルドが通れば次に進む。  
Step5 ではじめて影が見える。

| Step | 何をするか | ビルド後の状態 |
|------|-----------|--------------|
| [Step1](./Step1.md) | ライト視点の行列を追加する | 変化なし |
| [Step2](./Step2.md) | シャドウマップ用テクスチャを作る | 変化なし |
| [Step3](./Step3.md) | 深度を書くだけのシェーダーを作る | 変化なし |
| [Step4](./Step4.md) | 2パス描画に切り替える | 変化なし |
| [Step5](./Step5.md) | シェーダーで影を判定する | 影が出る |

---

## スタート地点の確認

コミット 8eee953 の時点で以下がすでに動いている。

- Simple3D.hlsl の PS() でランバート拡散反射（平行光源・点光源切り替え）
- WASD キーでライト方向を変えられる
- CONSTANTBUFFER_STAGE で lightPosition / eyePosition / lightType をシェーダーに送っている

これを壊さないように追加していく。
